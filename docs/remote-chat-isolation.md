# 远程聊天会话隔离

> 状态: 已落地 | 最后核对: 2026-09-14

Telegram、飞书和 QQ 的一个机器人连接可以服务多个私聊或群聊。机器人连接只保存凭证、能力授权和新聊天的初始配置；每个具体聊天以 `(connectionId, externalId)` 为键保存自己的会话、项目、渠道、模型、Agent、推理强度和权限模式。列表的数字选择状态也按这个键隔离。

旧连接只有一个明确的允许聊天或配对目标时，该目标首次发消息会继承旧默认会话。目标不唯一时不推测归属，各聊天首次使用时分别新建会话。后续命令只修改当前聊天绑定，不修改同一机器人下其他聊天的配置。会话列表隐藏其他聊天已占用的会话，一个会话不能意外绑定到同一机器人的两个聊天；跨连接共享仍需要相关连接显式开启共享。

定时任务完成后，仅当其会话恰好绑定到一个已启用的远程聊天时才回传到该聊天。零个或多个聊天匹配时不发送远程消息；不再取白名单或配对列表的第一项作为目标。旧配置在聊天首次建立绑定前，定时结果不会自动远程投递。
